# SmartLook-AI — Frontend Web (Angular)

Generar el proyecto (requiere Node.js):

```bash
npm install -g @angular/cli
cd frontend-web
ng new . --directory=. --routing --style=scss
```

Estructura sugerida, reflejando los módulos del backend:
`catalogo/`, `disponibilidad/`, `reservas/`, `carrito/`, `checkout/`, `vestidor-ar/`, `perfil/`, `admin/`.
