Cómo funciona

  • El chatbot primero busca datos reales (productos, reservas, sucursales) y se los pasa al modelo para que redacte la respuesta — nunca deja que la IA invente datos por su cuenta.
  • Si el proveedor configurado no responde (apagado, sin API key, error de red), el chatbot sigue funcionando con respuestas basadas en reglas, sin cortarse.
  • Para usar un modelo local (Ollama), tiene que estar corriendo en tu máquina — este proyecto no lo instala ni lo inicia por vos.
